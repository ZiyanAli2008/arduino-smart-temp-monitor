# Arduino Smart Temperature & Humidity Alert System

Built using Arduino Uno and DHT11 sensor.

## Features
- Reads live temperature and humidity
- Green LED = safe
- Yellow LED = caution
- Red LED = danger
- Buzzer activates above 80°F
- Serial Monitor output

## Components
- Arduino Uno
- DHT11
- LEDs
- Buzzer
- Breadboard
- Jumper wires

## Skills Demonstrated
- Embedded systems
- Sensor integration
- Conditional logic
- Hardware debugging
